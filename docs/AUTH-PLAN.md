# 認証の追加

- ユーザーは実際のアクセス制限を選択。GitHub Pagesの一般公開は保留。
- グラデーション背景・中央のグラスモーフィズムのログインカード。メールとパスワード、表示切替、送信中・失敗状態。
- Next.js /loginのGET・POST・DELETEでログインとログアウト。資格情報は環境変数、パスワードはscryptハッシュ。
- joseのHS256署名付きセッション。8時間、HttpOnly・SameSite=Lax・本番Secure cookie。
- proxy.tsで静的アセットを含む全リクエストを保護。例外は自己完結したログインページとロゴのみ。
- 失敗回数制限、同一Origin確認、入力サイズ上限、ログイン画面CSP、認証前の配信・ログアウト後の再アクセスを検証。
- 認証コア・経路のテスト、型チェック、ビルド、独立レビュー。
- Next.jsを実行できるVercelを公開先とする。秘密情報はGitHubに含めない。
