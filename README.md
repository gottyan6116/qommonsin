# Qommons IN

行政職員がつながり、知見を業務の型へ育てる共創プラットフォームの提案用超MVPです。ホームの相談投稿から、全国行政AXレポジトリ、QommonsAIによる差分確認、改善案の共有まで操作できます。

## すぐに体験する

ソースフォルダーと同梱の **Qommons-IN-demo.html** をChromeまたはEdgeで開いてください。画像・React・スタイルを含む単体ファイルで、サーバーやインターネット接続なしで利用できます。ファイルURLにおけるlocalStorageの保存はブラウザの設定に依存します。安定した保存と開発には下記のNext.js版を使用してください。

## 起動

Node.js 22以上（開発環境は24）、npmが必要です。

```sh
npm ci
npm run dev
```

[http://127.0.0.1:3000](http://127.0.0.1:3000) を開きます。

```sh
npm run build
npm start
```

単体デモの再生成は `npm run build:demo`。出力はソースフォルダーの1階層上の `Qommons-IN-demo.html` です。

## 90秒のデモシナリオ

1. ホーム先頭の、青葉市・田中 美咲さんによる給付金申請の不備確認の相談を読む。
2. 朝凪市・佐藤 健太さんの効率化事例のコメントを見る。
3. 投稿の「関連AXパッケージ：給付金申請受付・審査」を開く。
4. 責任者承認済みの表示、業務フロー、不備ありの場合の補正・再提出、6つの構成要素を確認。
5. 「この型を使ってみる」を押す。
6. 紙／オンラインと庁内／外部審査を選び、「自庁との差分を確認する」。
7. 必要なら追加確認事項をメモする。
8. 「改善案を投稿する」で下書きへ。本文と関連パッケージを確認し、「投稿する」。

**「課題を発見 → 知恵を共有 → 業務の型 → 自庁で再利用 → 改善を還元」** の循環を体験できます。

## 実装機能

- 3カラムフィード、固定ヘッダー、深緑の独自ブランド、添付Polimillロゴ。
- 架空の職員6名と公式アカウント、初期投稿10件。画像、相談、事例、公式Tips、イベントで構成を変化。
- 投稿作成、2MB以下のJPEG・PNG・WebP・GIF添付とプレビュー、投稿種別、関連パッケージ。
- いいね、コメント、リポスト、引用、保存、フォロー、投稿・職員・自治体・部署の検索。
- 保存済み項目、ネットワーク、プロフィール、通知、イベント登録・コミュニティ参加のデモ。
- 6つのAXパッケージ、検索・分野・承認フィルター、概要、個別業務フロー、構成要素、ひな形のダウンロード、関連投稿。
- 申請受付・審査を中心とするシナリオAI、2つの運用差分、追加メモ、改善案への引き継ぎ。
- スマートフォンでは下部ナビゲーション。プロフィールメニューから保存・コミュニティ・イベントへ。
- 投稿・コメント・反応・保存・フォロー・リポストをlocalStorageに保存。破損データは初期状態へ戻し、容量不足は画面通知。
- プロフィールメニューの「デモの設定」から、確認画面を経て初期化。

イベント参加・コミュニティ参加・通知の既読はこのセッション内のみ保持します。

## 技術

Next.js App Router / React 19 / TypeScript / Lucide / CSS / esbuild。依存関係の正確なバージョンはpackage-lock.jsonに固定しています。複雑な状態管理・図ライブラリ・DBを追加せず、Reactの状態とCSSで構成しています。VercelでNext.jsプロジェクトとして扱えます。環境変数やAPIキーは不要です。

- `app/`：入口と全体スタイル
- `components/app-shell.tsx`：ナビゲーション、状態、プロフィール、各ダイアログ
- `components/feed.tsx`：フィード・投稿・コメント
- `components/repository.tsx`：レポジトリ、詳細、業務フロー、サンプル出力
- `components/ai-panel.tsx`：差分確認シナリオ
- `lib/`：型、検索・検証ロジック、架空データ
- `tests/`：ロジックとブラウザシナリオ
- `scripts/`：オフライン版の生成
- `docs/REQUEST.md`：ユーザー提供の開発指示書

## GitHub・GitHub Pages

対象は [gottyan6116/qommonsin](https://github.com/gottyan6116/qommonsin) です。

ルートの `index.html` は画像やスクリプトを含む単体デモです。GitHub PagesのSettings → Pagesで `Deploy from a branch`、ブランチ `main`、フォルダー `/(root)` を選んでSaveすると公開できます。公開先は [https://gottyan6116.github.io/qommonsin/](https://gottyan6116.github.io/qommonsin/) です。

Next.jsのサーバーをGitHub Pagesで動かす構成ではなく、同じReactアプリを単体HTMLへ生成して配信します。変更時は `npm run build:demo` を実行し、更新された `index.html` も一緒にコミットしてください。

GitHubへの反映は、権限のある環境から `git push origin HEAD:main` を実行します。

## デモ上の前提・未実装

- 人物、自治体、所属、投稿、数値、成果、承認状態、イベントはすべて架空。画像の人物と架空プロフィールに関係はありません。

- AIは定義済みのデモ回答で、自由入力を分析しません。外部AI APIへの送信はありません。
- 本番認証、DB、LGWAN、課金、監査、実業務への自動実行、職員プロフィールの編集は対象外です。
- 参照指示のPDF「全国行政AXレポジトリ_A4両面.pdf」は今回の添付にはなく、指示書に記載されたフローを実装しています。
- 通報・イベント登録などは画面内のデモ動作のみで、第三者に連絡しません。
